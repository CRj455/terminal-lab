#Semana 02 - fundamentos  y sistema de archivos

##Que hace 
‘ explorar - sistema .sh ‘ recorre 6 directorios de  la jerarquia FHS
 (/etc, /var,/home, /bin , /tmp y /proc) y para cada uno imprime su funcion y un listado
 real de su contenido.
## Archivos 
-‘ explorar - sistema .sh ‘ -script principal 
-‘ Salida-ejemplo .txt ‘ -salida  de l script o resultado 
-‘ README.md ‘este archivo
## Como se ejecuta
cd semana02
chmod +x explorar - sistema . sh
./ explorar - sistema . sh
./ explorar - sistema . sh > salida - ejemplo . txt
